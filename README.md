# tw1xty

Статичный сайт-визитка с живым персонажем. Без сборки и зависимостей — достаточно залить папку на любой хостинг.

## Структура

```
tw1xty-site/
├── index.html            разметка: персонаж, имя, три ссылки, кнопка
├── css/
│   ├── base.css          переменные, сброс, страница, заголовок, подвал
│   ├── background.css    северное сияние, холсты звёзд и искр
│   ├── mascot.css        персонаж: тело, уши, руки, глаз, лицо, настроения, состояния
│   ├── components.css    облачко, имя, карточки-ссылки, кнопка, тост
│   ├── scenes.css        сцены кнопки: свет, дискотека, копоть, обратный отсчёт
│   └── animations.css    все @keyframes и @property
├── js/
│   └── main.js           всё поведение, разбито на 37 пронумерованных секций
└── assets/img/           telegram.svg, discord.svg, vpn.png
```

Порядок подключения CSS в `index.html` важен (каскад) — не меняй его.

## Что где менять

| Что | Где |
|---|---|
| Адреса и подписи ссылок | `index.html`, блок «Ссылки» |
| Ник для копирования в Discord | `js/main.js`, секция «Реакции на наведение» (`byId("dc").onclick`) |
| Реплики персонажа | константы в `js/main.js` в UPPER_CASE: `HOVER_LINES`, `MONOLOGUE_LINES`, `STAR_LINES`, `NAME_LINES`, `TAB_TITLES`… |
| Подписи кнопки «НЕ НАЖИМАЙ» | `BUTTON_LABELS` в `js/main.js` |
| Цвета | переменные в начале `css/base.css` (`--v`, `--t`, `--b`, `--d`) |
| Сцены кнопки | `js/main.js`, секции «Сцена 1–5» + `css/scenes.css` |

## Как залить

Загрузи **содержимое** папки (а не саму папку) в корень сайта: `index.html`, `css`, `js`, `assets` должны лежать рядом.

- Обычный хостинг: в `public_html` / `www` через панель или FTP.
- Netlify Drop (app.netlify.com/drop): перетащить папку.
- GitHub Pages / Cloudflare Pages: залить в репозиторий, включить Pages.

Сайт нужно открывать по HTTPS (иначе копирование ника в Discord работает только через запасной способ).
